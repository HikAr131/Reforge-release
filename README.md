# 重塑（Reforge）

免费系统环境重塑工具，单文件便携，当前版本 **0.0.2**。这个软件免费公开分享，不出售，也不提供付费功能。

## 下载与使用

[下载最新版 Reforge.exe](https://github.com/HikAr131/Reforge-release/releases/latest/download/Reforge.exe) · [版本说明](https://github.com/HikAr131/Reforge-release/releases/latest)

适用于 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime；Windows 11 通常已内置。下载后直接运行 `Reforge.exe`，系统会请求管理员权限，无需安装。卸载时删除 EXE 即可；如需先清除设置、日志与更新缓存，可在「关于」选择「清除并退出」，恢复快照会保留。

包含常规清理 5 项、高级操作 7 项及恢复高级操作。请先阅读每项功能说明：这不是磁盘清理或电脑加速工具，会清理记录、读写注册表，并可更改网络、网卡与机器标识；操作可能导致断网、授权失效或文件丢失。不清楚影响时请不要尝试，并先备份重要数据。

高级操作执行前会确认风险并引导创建系统还原点；还原点不能恢复个人文件、已卸载程序数据或已清空的回收站内容。「恢复高级操作」只恢复快照记录的注册表和 hosts，系统级网络重置无法回滚。已有恢复快照继续保存在 `%APPDATA%\HikariClean\backups`。

## 更新

每次启动后台检查一次，也可在「关于」手动检查。新版本提供更新提示，可稍后再更新；下载时可以取消。更新清单经 Ed25519 签名验证，安装前核对文件大小与 SHA-256，更新后重新启动，失败时恢复旧版。

更新只连接 GitHub，网络无法连接时可从上方下载链接手动获取。原始码保存在作者的私有仓库，本仓库只提供正式发布文件与反馈渠道；不会向客户端内置任何 GitHub 令牌。
