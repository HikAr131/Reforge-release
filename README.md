# 重塑（Reforge）

免费系统环境重塑工具，单文件便携，当前版本 **0.0.5**。这个软件免费公开分享，不出售，也不提供付费功能。

## 下载与使用

[下载最新版 Reforge.exe](https://github.com/HikAr131/Reforge-release/releases/latest/download/Reforge.exe) · [版本说明](https://github.com/HikAr131/Reforge-release/releases/latest)

适用于 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime；Windows 11 通常已内置。下载后直接运行 `Reforge.exe`，系统会请求管理员权限，无需安装。卸载时删除 EXE 即可；如需先清除设置、日志与更新缓存，可在「关于」选择「清除并退出」，恢复快照会保留。

包含常规清理 5 项、高级操作 7 项、恢复高级操作及「ACE 优化」的进程调校、启动优先级、缓存清理、退出与卸载。请先阅读每项功能说明：这不是磁盘清理或电脑加速工具，会清理记录、读写注册表，并可更改网络、网卡与机器标识；操作可能导致断网、授权失效或文件丢失。不清楚影响时请不要尝试，并先备份重要数据。

高级操作执行前会确认风险并引导创建系统还原点；还原点不能恢复个人文件、已卸载程序数据或已清空的回收站内容。「恢复高级操作」只恢复快照记录的注册表和 hosts，系统级网络重置无法回滚。已有恢复快照继续保存在 `%APPDATA%\HikariClean\backups`。

「ACE 优化」可按需调整目标进程的 CPU 亲和性、优先级、效率模式、I/O 与内存优先级；监控只在重塑运行时生效，不新增 Windows 开机自启动，停止监控不会恢复已应用的限制。启动优先级会写入 HKLM IFEO，写入前备份首次原值；无备份清除需要明确确认。缓存清理只处理已验证目录中的可清理项，默认请求回收站但去向无法核实，可能永久删除；永久删除需再次确认。更强主动限制可能违反部分游戏用户协议，存在封号、异常或稳定性风险。

退出组件、运行官方卸载程序和清理残留仍保留；两种卸载都必须先成功创建并核验系统还原点，不能跳过；退出不经过此步骤。退出会导致正在运行的游戏掉线，卸载后游戏可能重新安装 ACE。还原点不能替代个人文件备份，新版风险声明需要重新确认。
